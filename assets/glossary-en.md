## 公司名处理规则（术语表没有时）
1. 有官方英文品牌（官网域名/英文媒体）→ 用官方英文名
2. 无官方英文 → 拼音 + 首次出现注释 `English (Chinese: 中文)`
3. 已通用英文名直接用：Tencent、Alibaba、Baidu、ByteDance、Kuaishou、Xiaohongshu (RED)、TikTok/Douyin、Mango TV、Mixue、Cainiao、Lalamove、Perfect Diary、China Merchants Bank、New China Life、SF Express、Trip.com Group、Meituan、JD.com、NIO、CATL 等
4. 人名：中国人名用拼音（Surname Givenname），首次出现加 (Chinese: 中文名)；西方人名保留原文（Klarna CEO Sebastian Siemiatkowski 等）

1. **任何地方不得出现 fly2ai.top / aiorg / ai-customer-growth.fly2ai.top 域名**——英文版只面向 GitHub 读者
